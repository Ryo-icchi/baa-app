# ばあ！ — 1歳から遊べる いないいないばあアプリ（PWA）

とびらをタッチすると、登録した写真（ぬいぐるみ・家族・ペット）が「ばあ！」と飛び出して、
録音したおうちの人の声が再生される。1歳児向けの「親子で遊ぶ因果遊びおもちゃ」。

姉妹アプリ: [すみながし](https://github.com/Ryo-icchi/suminagashi-baby)（墨流しお絵かき）

## 設計原則（1歳児向けアプリのベストプラクティス調査より）

調査レポート: ai-secretary `tasks/reports/toddler-app-research-20260612.md`

- **全画面が当たり判定** — 2〜3歳児でも狙った場所をタップできるのは27%という研究結果（PMC7303424）に基づき、ボタンを狙わせない
- **失敗・不正解の概念なし** — どう触っても「正解」。テキスト誘導なし・マルチタッチ不要
- **無音でも遊びが成立** — 電車・機内対応。音は加点要素（親メニューでON/OFF）
- **「教育」を狙わない** — 1歳児は画面から単独では学べない（video deficit）。本人が現実に知っているもの（自分のぬいぐるみ・家族）の写真を使うことで、画面と現実をつなぐ
- **自然な終了演出** — おやすみモード（月と星の静かな画面）でクールダウンして終わる
- **連続報酬・自動再生なし** — 「もっと」を煽る仕掛けを作らない

## つかいかた

### インストール（最初の1回）

1. iPhone/iPad の Safari で配信URLを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面の「ばあ！」から起動（フルスクリーン・オフライン動作）

### 写真と声の登録（親）

1. 画面を **2秒長押し** → 右上に出る「おとな」をタップ
2. 「しゃしんを えらぶ」→ お子さんのぬいぐるみ・家族・ペットを撮影 or 選択
3. 「こえを ろくおん」→ 「ばあ！」「〇〇だよ！」と短くひとこと（最長10秒・あとからでもOK）
4. ほぞんする

登録した写真・音声は**この端末の IndexedDB の中だけ**に保存され、外部送信は一切ない。
（このリポジトリはアプリの「ガワ」だけで、個人データは含まれない）

### 子どもの遊び方（説明不要）

| 操作 | 起きること |
|---|---|
| 画面のどこでもタッチ | とびらが開いて「ばあ！」写真が飛び出す + 声 + キラキラ |
| もう一度タッチ | とびらが閉じて、次のだれかに変わる |

登録が無いうちは内蔵のどうぶつ（くま・ねこ・うさぎ・ひよこ）が出てくる。

### 移動中の誤操作防止（推奨）

iOS の**アクセスガイド**を併用する:
設定 → アクセシビリティ → アクセスガイド を ON → アプリ起動中にサイドボタン3回押し。
ホームへの離脱・コントロールセンター・通知を全部ブロックできる。

## 開発

- 素の HTML/CSS/JS。ビルド不要
- ローカル確認: `python3 -m http.server 8899` → http://localhost:8899
- E2Eスモークテスト: `node test-e2e.mjs`（ヘッドレスChrome + CDP・30項目。事前に上記サーバーと `Chrome --headless --remote-debugging-port=9333` を起動）
- デプロイ: `./deploy.sh`（GitHub Pages）。更新時は `sw.js` の `CACHE` バージョンを上げること

## クレジット

- 内蔵の動物イラスト8種（くま・ねこ・うさぎ・ひよこ・いぬ・ぺんぎん・ぞう・ぱんだ）とUI: すべて本リポジトリのオリジナルSVG（くまさんの作画文法で統一）

## 著作権について

このアプリにキャラクター画像は同梱していない。家庭で撮影した写真（市販のぬいぐるみ等を含む）を
端末内でのみ使用するのは私的使用の範囲。**写真を含む状態での再配布・公開はしないこと。**
